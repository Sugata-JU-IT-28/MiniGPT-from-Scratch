# Samples from the final MiniGPT model

The modern architecture trained on 3,145,728 tokens at peak learning rate 0.0015. Its selected checkpoint scored 3.3017 nats/token and 2.1101 bits/byte on validation after reloading. [Training record and token IDs](../results/final_model.json)

Each prompt uses seed 0 and allows up to 96 new tokens. Within a prompt, temperature is the only sampling setting varied. Samples are unedited.
